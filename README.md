# Entregable1DAM - ITANES Tour

Aplicacion Android desarrollada para el caso practico de ITANES. Permite consultar un recorrido turistico de 5 puntos, trabajar sin conexion con SQLite, guardar favoritos y abrir rutas en auto con Google Maps. Cuando hay conexion, sincroniza informacion desde la API de Wikipedia mediante Retrofit y Gson; Glide gestiona las fotografias reales y su cache.

La documentacion completa del caso esta en [docs/ENTREGABLE_ITANES.md](docs/ENTREGABLE_ITANES.md).
